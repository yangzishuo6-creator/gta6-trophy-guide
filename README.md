An offline PlayStation 5 tracker and platinum roadmap for all 55 Grand Theft Auto VI trophies.

Run `node serve.ts` and open `http://localhost:8080`. Progress and the spoiler setting save in your browser. Export a JSON backup to move your progress. Import merges the earned trophies in a backup with your current checklist.

The missable filter is an availability watchlist of objectives tied to named contacts. The official descriptions give no confirmed cutoffs. Each revealed guide links to the Exophase and PSNProfiles trophy lists.

Run `mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts` to package the offline app, screenshots and make.fun dossier.
